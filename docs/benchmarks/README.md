# Measurement archive

These files record development experiments, including failed loads. They are
not product capacity guarantees. Reports retain numerical metrics, artifact
hashes, workload configuration and timestamps. Personal filesystem paths and
local service identities have been removed; the sanitized JSON files are not
byte-identical copies of the original local reports.

The current code does not reproduce every historical binary. Earlier measurements
remain for context, with their artifact hashes and limitations; use the current
[benchmark guide](../../tests/load/README.md) for new runs.

No source blocklist or real-domain query corpus is included here. Re-fetch source
files and generate local fixtures when reproducing a real-list workload.
